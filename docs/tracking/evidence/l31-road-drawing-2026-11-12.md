# L31 road drawing and preliminary takeoff — 12 November 2026

User requested one end-to-end L31 slice: drag/place roads, shape/line/curve editing, saved costs and estimates. Existing unrelated local changes were preserved. No dependency, migration, new endpoint, remote write or deployment was introduced.

## Implemented behaviour

- Layout > Roads and driveways: choose Option A/B, drag/click a route or supply numeric points, choose line/smooth curve/area shape, enter explicit width and source/provenance, then confirm or cancel. Up to 12 editable map handles/numeric control points. Numbered handles can be dragged; coordinate fields support keyboard editing. Cancellation makes no workspace write. Confirming makes one workspace undo step; explicit save retains the ordinary revision/history/recovery behaviour. Unconfirmed sketches remain component drafts and are not recovered after reload.
- `apps/api/app/roadwork.py`: bounded sampled Catmull-Rom curves or polygon areas; constant-width UTM buffering with flat caps, rounded joins and 0.01 m display-footprint simplification. This is a concept method, not an engineered road alignment or survey tolerance. The resulting supported simple polygon is validated by the ordinary quantity kernel. Self-crossing/invalid/out-of-bound/excess-complexity output is rejected. The footprint union is measured once; overlapping separate proposed roads are rejected rather than silently double-counted. Existing Baseline road context does not block proposed resurfacing.
- `workspace.py`, `spatial_editor.py`, `main.py`: road metadata persists alongside ordinary area work. Existing authorised spatial-edit API handles preview/confirmation validation and expected-revision checking. Route edits preserve layer/rate metadata, regenerate footprint and quantities, and retain prior estimates. Generic spatial transforms direct road users back to the road controls. No fabricated dimensions, layer thicknesses or prices are supplied.
- `RoadEditor.tsx`, `road-editor.css`, `DrawingMap.tsx`, `GeometryWorkspace.tsx`, `StudioShell.tsx`, `domain/workspace.ts`: immediate cursor route feedback, backend footprint preview, stale-response protection, explicit confirmation/cancel, saved road cards, layer/cost and estimate entry points. Sketches block conflicting scenario/tool/save operations. Existing map controls/neutral fallback remain available; map disposal is guarded.
- `PlantMaterialPanel.tsx`: road selection opens the existing material/component record workflow. A new route starts with blank material/source and zero thickness requiring user input; missing layers/rates remain unpriced. Road layers use explicit uniform m3 takeoff and compatible selected sourced rates. Existing workspace saves, schedule/BOQ CSV, and retained preliminary estimate APIs remain authoritative.
