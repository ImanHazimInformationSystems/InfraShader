# L04 audit — 29 October 2026

Scope: repository audit and unified L02/L04/L06/L07 interaction definition, requested by the user. No application implementation changes. Existing branch `build/l07-object-palette`; unrelated dirty work preserved. No deployment, remote write, paid service or Excel export.

## Findings

| Capability | Evidence and limitation |
|---|---|
| Single selection and editing | `apps/web/src/components/DrawingMap.tsx` configures Terra Draw polygon/line/point modes and single-feature drag/vertex editing. `GeometryWorkspace.tsx` connects selected geometry to a numeric coordinate form. Persistent named/saved selection across sessions is not established. Tab draft recovery includes editing ID, not a general selection library. |
| Numeric editing | General WGS84 coordinates, building height/count and overrides exist. L07 adds metre-based translation, rotation and scale for presets through `apps/api/app/workspace.py::transform_objects`. General edge-length/width constraints and offsets for arbitrary geometry are not implemented in the inspected path. |
| Snapping | `apps/api/app/object_palette.py::place` snaps preset anchors to a projected grid. Terra Draw configuration does not enable general vertex/edge snapping. These are different capabilities. |
| Duplication and groups | `ObjectPalette.tsx` duplicates a preset with a new ID and supports named preset groups; backend translates/rotates/aligns supported instances. No general polygon/line duplicate/array or arbitrary multi-selection tool found. |
| Undo and revisions | `GeometryWorkspace.tsx::change` keeps 50 workspace draft snapshots and clears redo. Apply and save are separate; server workspace history/restore is revisioned. This is not evidence of continuous drag-stroke undo grouping or persistent undo after reload. |
| Layers, hide and lock | Fixed geometry/category view toggles; preset visibility and editor lock. Hidden items remain in quantities. No general named-layer tree or general geometry locking found. Editor locks are not backend permission grants. |
| Search | Preset catalogue search/filter exists. A unified search across arbitrary project entities was not established. |
| Holes, split/merge | `apps/api/app/domain/geometry.py` explicitly rejects holes and multipart geometry. UI says no holes. Split/merge/arrays remain NEXT scope, not quietly accepted. |
| Explore transition | `ExploreWorkspace.tsx` passes bounds and `App.tsx` navigates to project creation. No full editable provider-building import or unified scene transition. |
| Terrain / object integration | `TerrainPanel.tsx` is a separate grid/diagram. `ObjectScene.tsx` is a separate Three scene. `DrawingMap.tsx` disables flat-ground building 3D on edited terrain. Current representative-point contacts do not imply foundations fitted to a surface. |

Conclusion: L04 is **Partial**, not absent or complete. Existing checks pass for the supported subset; full L04 verification remains **Not run**, deployment **Local only**, acceptance **Pending**. Original compound acceptance rows 001–004 remain Not run because their full behaviour is not implemented/verified. Row 005 is Passed for the inspected visibility/quantity contract, not customer acceptance.
