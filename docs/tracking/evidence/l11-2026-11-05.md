## Implemented scope and evidence

`apps/api/app/shade_studies.py` supplies bounded explicit-offset bands, duration-weighted midpoint sampling, target heatmap, source area-time, contribution summaries, project permissions, idempotent persistence and historical/stale reads. It reuses `domain/shade.py` rather than a second shadow engine. The latter adds optional contribution/source outputs without changing single-time shadow projection. `main.py` exposes project-scoped GET/POST study routes; `calculations.py` keeps study artifacts out of legacy analysis/estimate/issue lists and flags study model changes stale.

`ShadeStudies.tsx` provides the ground-workspace study form, saved history, scenario cards, time chart/table, numerical source drilldown and schematic. `CalculationsPanel.tsx` integrates it with existing dirty-form handling. `DrawingMap.tsx` accepts backend heatmap colours in the existing shadow-overlay layer. Old single-time overlays retain their default colour. No schema migration or production dependency was needed.

The implementation contract and scientific boundaries are in [shade-studies.md](../../shade-studies.md). Read-only and foreign-project checks are backend checks, not UI-only restrictions. No cost/pricing data is added to study payloads.
