## Implemented scope

Twelve original project-authored MIT primitive presets cover benches, bins, lighting, toilets, pergolas, solar modules, play equipment, bike racks, planters, paths, fencing and planting. This is the bounded concept set described by F19, not the deferred large detailed/manufacturer library. See [usage, rights and limits](../../object-palette.md).

- `scripts/object-assets.py`, `apps/api/app/data/catalogue.json`, `apps/web/public/objects/`: reproducible versioned definitions, nominal dimensions, ground pivots, unit/category, part/triangle limits, source hashes, MIT notice and schematic thumbnails. Backend/frontend catalogues match byte for byte.
- `apps/api/app/object_palette.py`: strict instance transforms, admitted preset/version lookup, projected grid snapping, full-footprint boundary checks, canonical count/length quantities and scenario terrain contact/elevation offsets.
- `apps/api/app/workspace.py`, `main.py`: authorised preview/group operations, independent proposed instances and shared Baseline rules, private revisioned JSON, canonical pose reconstruction on save/read/restore, stale-write handling and existing rate-link preservation. No database migration.
- `apps/web/src/components/ObjectPalette.tsx`: search/filter, dimensions/rights, numeric place/edit/rotation/scale/elevation/snap, duplicate/hide/lock/delete, groups and category view layers.
- `ObjectScene.tsx`: lazy Three.js instanced rendering, orbital navigation, picking, terrain-aware contact preview, bounded on-demand frames, resource disposal, WebGL failure/context-loss messages and numeric/2D fallback.
- `domain/objects.ts`, `domain/workspace.ts`, `GeometryWorkspace.tsx`: validated schema/request sanitisation, map footprints, existing undo/redo and pricing integration, pending-field/navigation state and locked-instance editor deletion guard.
- `apps/api/app/domain/shade.py`: explicit decorative-object exclusion in numerical shade limitations. Solar presets make no energy-output claim.
