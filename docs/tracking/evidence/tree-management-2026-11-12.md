## Decision and implementation

Read repository guidance, L02/L04/L11 specifications and tracking records, build plan, decisions, validation and UI coverage/design before feature work. Inspected existing map/provider-height buildings, site locator, solar/environment, object/terrain/quantity workflows, project schemas/API/DemoStore and revision/permission/history paths. The architectural decision was stated before implementation: retain MapLibre/OpenFreeMap/Photon and add separately sourced tree inventory, with no Mapbox migration/credentials or automatic global coverage claim. Contract: [tree-management.md](../../tree-management.md).

`TreeWorkbench.tsx` supplies source lookup/import/manual/map placement, inside-locator review, explicit dimension basis/unknowns, per-tree and bulk retain/remove, bounded undo/redo, source details and separate context/project/removed visibility switches. `TreeMapLayer.tsx` / `tree-scene.ts` render retained, dimensioned trees as instanced simplified trunks/crowns; unknowns remain markers and removal decisions retain red markers. Attribution is escaped in the map attribution control. The optional flat-ground ellipsoid shadow preview is display only, gated by available daylight/terrain. `MapTerrainContext.tsx` exposes optional configured raster DEM with no default dataset. Existing provider buildings and coordinate fallback remain connected.

`ProjectTreeWorkbench.tsx`, `GeometryWorkspace.tsx`, `StudioShell.tsx` and `App.tsx` connect the editor to new-project transfer and saved-project Site trees tool. Tree drafts contribute to unsaved-navigation state. Explicit tree saves use existing project revisions separately from workspace saves; expected revision stays attached to the inventory until successful save/reload. Read-only/archived UI retains review while disabling writes. Closing the panel ends map placement; the geographic drawing tool is disabled during tree placement/review. Sun context uses the existing solar service and a collapsible control; environment styling preserves project geometry/tree colours.

`tree_inventory.py`, `schemas.py` and `projects.py` add bounded unique tree records to existing project site JSONB and history payloads. Existing backend project edit grants and atomic revision checks remain authoritative. Legacy locator-only site updates preserve omitted inventories. No database migration/new write route or analytical solver extension. Geographic transfer remains WGS84; display metre scale is explicitly visual Mercator, with no new quantities. Existing analytical projected CRS and Decimal money rules are unchanged.

Source context lookup: explicit Overpass read, bounded envelope/record count, timeout, byte cap, cancellation, cache and cooldown. Browser test intercepts this request; no live coverage is claimed. GeoJSON parsing requires source/permission attribution, Point geometry, finite coordinates and stable IDs; malformed or duplicate inventories fail without replacing prior context. Optional dimensions are not invented. OSM attribution/licence obligations and unknown coverage are disclosed. User-supplied licence text is recorded, not independently verified.

## Remaining gates

No complete or surveyed tree inventory, real tree/species/height validation, live OSM/Photon/OpenFreeMap service qualification, live DEM tile/vertical-datum qualification, satellite viewing, or field-accurate shade is established. Missing trees require manual entry or an appropriately licensed inventory. DEM rendering remains opt-in and unqualified without an approved dataset; the flat map/concept terrain workflow remains usable. Simplified tree crowns and solid shadow silhouettes are contextual, excluded from L11 analytical studies and issued quantities. Existing stale/unavailable gates remain.

No real Supabase Auth/Storage run, physical touch, assistive technology/screen-reader review, load qualification for many users, pilot/customer acceptance or deployment. Tree drafts live in memory until explicit apply/save; they do not use the geometry session-recovery store. No provider account, secret, paid resource, external message, remote write, push or deployment. F13/F16–F20 remain gated.
