## Purpose

Dependency-aware change impact and consistency check

## Trigger and prerequisites

Saved Studio project with sourced boundary, relevant project grants and drawn area/path or explicit count. See docs/plant-material-schedules.md for the supported CORE contract.

## Inputs and sources

User-supplied scientific/common names, nursery and crown assumptions, availability/substitution notes or approved material/finish/width/height recipes; immutable dated catalogue rates. No inferred horticultural suitability or engineering certification.

## Outputs

Revision-bound source schedules, canonical quantities, component estimate lines, source-linked preliminary BOQ CSV and changed-input/quantity/base-cost explanations. Details: docs/plant-material-schedules.md. Documentation clarification (12 November 2026): Change-impact refinement: object/source revision -> declared measurement/plant/material schedule -> quantity -> explicit rate selection -> estimate/study -> proposal. Invalidate/review affected drafts; never silently change selected rate versions or issued outputs. See docs/measurement-and-estimating.md and docs/contractor-workflow.md.

## Permissions and confidentiality

Existing project grants protect read/edit; backend validation and revisions authoritative. Internal-pricing permission required for costs/differences. Restricted values stay unavailable, never zero. No cross-tenant source/rate access.

## Validation and failure states

Dimensions, finite ranges, count limits, recipe approval, inclusive-versus-component pricing, duplicate included labour/charges and stale revision checks. Preserve last valid draft on failure. Hidden items remain in quantities.

## Revision/history

Definition version increments on saved change; copied project-library entries are independent. Workspace restore strips derived schedules and recomputes them as a new revision. Saved estimates stale on revision change; issued snapshots unchanged.

## Explicit exclusions

Plant/material quantities now connect through canonical schedules, rates and saved estimates; item-level source changes and base-cost differences are visible. Full all-input dependency graph/review lifecycle and every edit/delete/duplicate/rate-replacement combination remain unverified. Existing conservative staleness and immutable issues retained. This clarification does not approve full vehicle-road construction, terrain earthworks/pond costing, automatic real supplier pricing or survey/field accuracy. PROP-ROAD-01 and PROP-EARTH-01 are unapproved proposals in docs/UI_CONCEPT_RECONCILIATION.md; existing priorities/statuses remain unchanged.
