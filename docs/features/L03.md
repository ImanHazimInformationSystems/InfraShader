## Purpose

Connect observations to design decisions.

## Trigger and prerequisites

Open an authorised real Studio workspace with a validated boundary. Create or review a constraint; verification requires measured/supplied source, verifier/date/reference. Genuine utility/setback information must be supplied.

## Inputs and sources

User-supplied private notes/photos, source type/reference, uncertainty, optional WGS84 location with consent basis, inspection date, target/work-item IDs, assigned person/due date and supplied verification reference. No implicit EXIF location import or automatic external verification.

Private register and map layer, critical/due-sorted verification queue, design response/resolution, immutable workspace source history, anonymous frozen count summary in issued outputs. ## Permissions and confidentiality

Project read/edit grants apply; active photo links must belong to this project. Location requires permission and basis. Private notes/geotags/person names are not automatically published; only counts/limitation text. Photo issuance remains explicit opt-in.

## Validation and failure states

Up to 100 constraints, 20 photo and 30 design links per record; no duplicate IDs/links; geometry inside site boundary; no missing design references. Map-derived/traced/estimated records cannot claim verification; geotagged observations and measured records need inspection dates. Resolution needs a result. Invalid edits retain form; save conflicts retain draft.

## Revision/history

Register saved in workspace revisions with actor; old source values preserved. Restore creates a new revision and invalidates current results. Linked evidence cannot be archived until unlinked and saved. Unapplied forms have navigation guards but are not independently persisted across reload.

## Explicit exclusions

No utility detection, automatic setback/no-work enforcement, survey certification or inferred legal compliance. Constraint geometry is never billable geometry. Wider K05 override/quantity impact and L20 checks remain separate. Field/customer/device acceptance not implied. This clarification does not approve full vehicle-road construction, terrain earthworks/pond costing, automatic real supplier pricing or survey/field accuracy.
